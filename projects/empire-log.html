Empire Logistics

January 21st, 2026 GitHub Website

Overview

The Empire Logistics page is a page dedicated to the Empire Lion Dance LLC team that myself and 2 others manage. The purpose of this site is to have a centralized location of gaining availability of our performers and a place for our members to see our upcoming performances.

Project Goal

The team needed a centralized place to keep track of which performances were coming up and needed performers. Members would frequently rely on managers to know which performances they were doing and when they'll be needed next. Knowing members also did not want to create a new account for already established applications, a site was the best decision to complete these requirements.

Tech Stack

Written in HTML, CSS, and JavaScript, along with Netlify Forms.

Results and Review

The project initially started off with just the form. As I've had experience using the form feature from Netlify creating my portfolio, Netlify was a great option to host this webpage.

The website is also designed for a mobile experience, as reminders are sent to a group chat on primarily IPhones, it was in the teams best interest to have a mobile friendly website.

Though collecting availability was now solved, members still requested to see which performances they were required to go to. Being able to reuse my card styles, I added a new page to see the current lineups for each performance, allowing members to find when they are needed are record it in their own calendar.

Overall the project was able to achieve the goals required. The only things that I would have enjoyed would have been to format the buttons for navigation a bit better, as on the website they can look out of place, even though the placement is designed for a mobile experience.
